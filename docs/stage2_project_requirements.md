# Stage 2: Project Requirements & Development Plan

## 1. Project Requirements

The Linux System Performance Monitor Using C++ is a Linux-based application that collects and displays important system performance information.

The main requirements of the project are:

- The application should run on Linux.
- The application should be developed using C++.
- The application should display CPU usage.
- The application should display memory usage.
- The application should display system uptime.
- The application should provide basic process information.
- The application should provide basic Linux system information.
- The application should be simple to operate from the terminal.
- The project should use Linux system interfaces to obtain system information.
## 2. Functional Requirements

The system should provide the following functions:

1. CPU Monitoring
   - Read CPU information from the Linux system.
   - Calculate and display CPU usage.

2. Memory Monitoring
   - Read memory information from Linux.
   - Display total, used, and available memory.

3. System Uptime
   - Read the system uptime.
   - Display the uptime in a readable format.

4. Process Monitoring
   - Identify running processes.
   - Display basic process information such as process ID and name.

5. System Information
   - Display basic information about the Linux system.
   - Display relevant kernel or system details.

6. User Interface
   - Display the collected information clearly in the terminal.
## 3. Non-Functional Requirements

- The application should be reliable during normal operation.
- The application should have reasonable response time.
- The source code should be organized into suitable modules.
- The program should be compiled using a C++ compiler on Linux.
- The application should use Linux system interfaces appropriately.
- The project should be maintained using Git for version control.
- The program should be easy to understand and operate from the terminal.

## 4. Project Modules

The project will be divided into the following modules:

- CPU Monitoring Module
- Memory Monitoring Module
- System Uptime Module
- Process Monitoring Module
- System Information Module
- Terminal Display Module
- Linux System Interface Module

Each module will have a specific responsibility so that the project remains organized and easy to maintain.

## 5. Project Scope

### Included in the Project

- CPU usage monitoring
- Memory usage monitoring
- System uptime monitoring
- Basic process information
- Basic Linux system information
- Terminal-based display
- C++ implementation
- Linux system interface usage
- Git-based version control

### Not Included in the Initial Scope

- Graphical user interface
- Remote system monitoring
- Cloud monitoring
- Network monitoring
- Advanced process management

## 6. Project Deliverables

The final project will include:

- C++ source code
- Header files
- Working Linux executable
- Project documentation
- System architecture documentation
- UML diagrams where applicable
- Test documentation
- README.md
- Git repository with development history
- Final project demonstration

## 7. Development Plan

The project will be developed incrementally.

### Phase 1
Project introduction and problem definition.

### Phase 2
Requirements analysis and development planning.

### Phase 3
System architecture, module design, data structures, and UML diagrams.

### Phase 4
Implementation of the basic monitoring prototype and integration of core modules.

### Phase 5
Testing, debugging, integration, and performance improvements.

### Phase 6

Final implementation, documentation, demonstration, and presentation.
